How to Run Locally (Live Server)

EventHive is built with pure HTML5, CSS3, and Vanilla JavaScript with zero external framework dependencies. Follow these quick steps to run it locally on your computer:

  1. Open Folder in VS Code: Download or extract the project folder containing index.html, style.css, and script.js, and open it in Visual Studio Code.
  2. Install Live Server Extension: In VS Code, press Ctrl+Shift+X (or Cmd+Shift+X on macOS), search for "Live Server" (by Ritwick Dey), and click Install.
  3. Launch the Website: Right-click on index.html in the file explorer and select "Open with Live Server" (or click "Go Live" in the bottom blue status bar).
  4. Explore & Test: Your browser will automatically open http://127.0.0.1:5500/index.html. Bookmarking events, searching, filtering, and switching between the 3 roles (Student, Organizer, Admin) will immediately work and persist via LocalStorage.
Academic / Mini-Project Note: This application requires no Node.js runtime, Python server, or database installation to demonstrate. It runs out of the box in any modern browser!
